## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → app | The `tourSeen` flag (read/written by this effect) is user/attacker-editable client state |
| navigator.languages → app | Device-reported language tags flow into `resolveTourLocale`; untrusted-ish string input from the browser environment |
