<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage 'language' → onPopoverRender dir decision | Stored locale drives an imperative DOM attribute write on the popover |
| CSS max-width/flex → browser layout | Pure client-side layout; no data crosses a trust boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Tampering | onPopoverRender writing `popoverDom.wrapper.dir` from `RTL_LOCALES.has(language)` | mitigate | `language` is a `Language` union value from `languageAtom`; the write is a fixed `'rtl'`/`'ltr'` string chosen by a `Set.has` membership test — never the raw stored value written to the DOM, so a tampered localStorage locale cannot inject an arbitrary attribute value. `dir` is set only on the detached popover node, never `<html>`/`<body>`. |
| T-03-06 | (n/a — CSS layout only) | responsive max-width, 44px min-height, [dir=rtl] flex-reverse | accept | Pure CSS; no input, no injection, no persistence. |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages this phase (RESEARCH.md §Package Legitimacy Audit: N/A). No install step. |
</threat_model>
